# 扭摆法测转动惯量 — 报告书写要点与评分标准

---

## 一、实验报告书写要点（评分标准）

### 1. 实验数据与处理部分

- **逐个算出各直接测量量的平均值、不确定度和相对不确定度的处理结果**  
  （注：平均值和标准偏差直接给出计算结果；其他计算过程要满足有**公式**、**数据代入**和**计算结果及单位**三个要素。）

- **间接测量量的计算**（代入数据并计算结果）

- **间接测量量不确定度的计算**（代入数据并计算结果）  
  （注：中间计算过程，不确定度保留 **2 个有效数字**）

### 2. 实验结果部分

实验结果应先用文字叙述清楚，再给出规范的**结果表达式**。  
（注：不确定度的表达结果保留 **1 个有效数字**，遵循 **"逢数进位"** 原则；平均值结果的尾数应与不确定度的尾数对齐，遵循 **"四舍六入五凑偶"** 原则。）

## 二、数据处理过程示例

### （一）测球体的转动惯量

#### 1. 各直接测量量平均值及其不确定度的计算

仪器误差：  
- 电子天平：Δm = 0.05 g  
- 游标卡尺：Δm = 0.02 mm  
- 秒表：Δm = 0.05 s

##### 对 M

\[
\bar{M}=(\text{结果}),\quad
u_M = \frac{\Delta_m}{\sqrt{3}} = (\text{代入数据}) = (\text{结果}),\quad
E_M = \frac{u_M}{\bar{M}} = (\text{结果})
\]

##### 对 D

\[
\bar{D} = (\text{结果}),\quad S_D = (\text{结果})
\]

\[
u_A = \frac{S_D}{\sqrt{n}} = (\text{代入数据}) = (\text{结果}),\quad
u_B = \frac{\Delta_m}{\sqrt{3}} = (\text{代入数据}) = (\text{结果})
\]

\[
u_D = \sqrt{u_A^2 + u_B^2} = (\text{代入数据}) = (\text{结果}),\quad
E_D = \frac{u_D}{\bar{D}} = (\text{结果})
\]

> 相同的步骤，分别计算得到 t₁、t₂、t 的不确定度的大小。

---

#### 2. 物体转动惯量的计算

##### （1）圆柱体转动惯量

\[
I_0 = \frac{1}{8} M \bar{D}^2 = (\text{代入数据}) = (\text{结果})\ \mathrm{kg \cdot m^2}
\]

\[
E_{I_0} = \sqrt{E_M^2 + (2E_D)^2} \times 100\% = (\text{代入数据}) = (\text{结果})
\]

##### （2）球体的转动惯量

由公式 \( K = \frac{4\pi^2 I_0}{T_2^2 - T_1^2} \)，代入 \( I = \frac{K}{4\pi^2} T^2 \) 可推得：

\[
\bar{I} = \frac{\bar{T}^2}{\bar{T}_2^2 - \bar{T}_1^2} I_0
       = \frac{\bar{t}^2}{\bar{t}_2^2 - \bar{t}_1^2} I_0
       = (\text{代入数据}) = (\text{结果})\ \mathrm{kg \cdot m^2}
\]

##### （3）球体转动惯量不确定度

\[
E_I = \sqrt{ \left( \frac{2u_t}{\bar{t}} \right)^2
           + \left( \frac{u_Y}{\bar{Y}} \right)^2
           + E_{I_0}^2 } \times 100\%
     = (\text{代入数据}) = (\text{结果})
\]

\[
u_I = E_I \, \bar{I}
\]

其中，令 \( Y = t_2^2 - t_1^2 \)，则  
\[
\bar{Y} = \bar{t}_2^2 - \bar{t}_1^2,\quad
u_Y = \sqrt{ (2\bar{t}_2 u_{t_2})^2 + (2\bar{t}_1 u_{t_1})^2 }
\]

##### 实验结果表达

扭摆法测定球体转动惯量的测量结果为：

\[
I = \bar{I} \pm u_I \quad (\text{单位}) \qquad (P = 68.3\%)
\]

> 注：计算结果用科学计数法表示，不确定度保留 **1 位有效数字**。
