## 问题1：0-4评分法计算各功能权重

### 0-4评分法规则

| 重要程度 | 评分 |
|:---:|:---:|
| 很重要（非常重要） | 4 : 0 |
| 较重要（比较重要） | 3 : 1 |
| 同样重要 | 2 : 2 |

> 总分 = n(n-1)/2 × 4，本题 n=5，总分 = 10×4 = **40**

### 分析功能重要程度关系

由题意可知：
- F1和F2同样重要 → F1 vs F2 = **2:2**
- F4和F5同样重要 → F4 vs F5 = **2:2**
- F2相对于F3很重要 → F2 vs F3 = **4:0**
- F1相对于F5较重要 → F1 vs F5 = **3:1**

根据等价关系推导：
- F1=F2，故 F1 vs F3 = F2 vs F3 = **4:0**
- F1=F2，故 F2 vs F5 = F1 vs F5 = **3:1**
- F4=F5，故 F1 vs F4 = F1 vs F5 = **3:1**
- F1=F2, F4=F5，故 F2 vs F4 = F1 vs F5 = **3:1**
- F4较重要于F3（F4对F1得1分，F3对F1得0分），故 F3 vs F4 = **1:3**
- F4=F5，故 F3 vs F5 = **1:3**

### 0-4评分表

| | F1 | F2 | F3 | F4 | F5 | 得分 | 权重 |
|:---:|:---:|:---:|:---:|:---:|:---:|:---:|:---:|
| **F1** | × | 2 | 4 | 3 | 3 | **12** | **0.300** |
| **F2** | 2 | × | 4 | 3 | 3 | **12** | **0.300** |
| **F3** | 0 | 0 | × | 1 | 1 | **2** | **0.050** |
| **F4** | 1 | 1 | 3 | × | 2 | **7** | **0.175** |
| **F5** | 1 | 1 | 3 | 2 | × | **7** | **0.175** |
| **合计** | | | | | | **40** | **1.000** |

各功能权重为：F1=0.300，F2=0.300，F3=0.050，F4=0.175，F5=0.175

## 资金时间价值系数说明

### 符号含义

系数符号格式为 `(已知/求, i, n)`，各字母含义：
- **A** = Annuity（年金）
- **P** = Present Value（现值）
- **F** = Future Value（终值）
- **i** = Interest Rate（利率）
- **n** = Number of Periods（期数）

斜杠左边是已知的，右边是要求的。例如 `(A/P,6%,30)` 表示已知现值P、利率6%、期数30，求等额年金A。

### 六个常用系数

| 符号 | 名称 | 公式 |
|:---:|:---:|:---|
| (F/P, i, n) | 一次支付终值系数 | $(1+i)^n$ |
| (P/F, i, n) | 一次支付现值系数 | $\frac{1}{(1+i)^n}$ |
| (F/A, i, n) | 等额年金终值系数 | $\frac{(1+i)^n - 1}{i}$ |
| (A/F, i, n) | 偿债基金系数 | $\frac{i}{(1+i)^n - 1}$ |
| (P/A, i, n) | 等额年金现值系数 | $\frac{(1+i)^n - 1}{i(1+i)^n}$ |
| (A/P, i, n) | 资金回收系数 | $\frac{i(1+i)^n}{(1+i)^n - 1}$ |

### 常用关系

- $(A/P) = (A/F) + i$（资金回收系数 = 偿债基金系数 + 利率），本题残值计算用到了此关系
- $(P/F) \times (F/P) = 1$，$(A/P) \times (P/A) = 1$（互为倒数）

## 问题2：计算两方案的年费用

### 方案1（寿命30年）

投资50000万元，年维护费1100万元，第10年、第20年大修各3500万元，残值为0。

AC₁ = 50000×(A/P,6%,30) + 1100 + 3500×(P/F,6%,10)×(A/P,6%,30) + 3500×(P/F,6%,20)×(A/P,6%,30)

= 50000×0.0726 + 1100 + 3500×0.5584×0.0726 + 3500×0.3118×0.0726

= 3630 + 1100 + 141.89 + 79.23

**AC₁ = 4951.12 万元**

### 方案2（寿命60年）

投资150000万元，年维护费1300万元，第20年、第40年大修各4000万元，残值8000万元。

AC₂ = 150000×(A/P,6%,60) + 1300 + 4000×(P/F,6%,20)×(A/P,6%,60) + 4000×(P/F,6%,40)×(A/P,6%,60) − 8000×(A/F,6%,60)

其中 (A/F,6%,60) = (A/P,6%,60) − i = 0.0619 − 0.06 = 0.0019

= 150000×0.0619 + 1300 + 4000×0.3118×0.0619 + 4000×0.0972×0.0619 − 8000×0.0019

= 9285 + 1300 + 77.20 + 24.07 − 15.20

**AC₂ = 10671.07 万元**

## 问题3：价值工程评价

### 功能加权得分

方案1: 5×0.300 + 8×0.300 + 4×0.050 + 9×0.175 + 6×0.175 = 1.5 + 2.4 + 0.2 + 1.575 + 1.05 = **6.725**

方案2: 10×0.300 + 9×0.300 + 7×0.050 + 9×0.175 + 9×0.175 = 3.0 + 2.7 + 0.35 + 1.575 + 1.575 = **9.200**

### 成本指数

CI₁ = AC₁/(AC₁+AC₂) = 4951.12/15622.19 = **0.317**

CI₂ = AC₂/(AC₁+AC₂) = 10671.07/15622.19 = **0.683**

### 功能指数

FI₁ = 6.725/(6.725+9.200) = 6.725/15.925 = **0.422**

FI₂ = 9.200/15.925 = **0.578**

### 价值指数

VI₁ = FI₁/CI₁ = 0.422/0.317 = **1.332**

VI₂ = FI₂/CI₂ = 0.578/0.683 = **0.846**

### 方案选择

VI₁ = 1.332 > 1 > VI₂ = 0.846，**方案1的价值指数最大，应选方案1**。
