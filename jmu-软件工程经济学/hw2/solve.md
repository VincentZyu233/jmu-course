# 作业2 题解

## Problem 1：内部收益率敏感性分析

### 1. 基本方案净现金流

| 年份 | 0    | 1    | 2    | 3    | 4    | 5    | 6    | 7    | 8    |
|:---|:---:|:---:|:---:|:---:|:---:|:---:|:---:|:---:|:---:|
| 净现金流量（万元） | -2500 | 450 | 450 | 450 | 450 | 450 | 450 | 450 | 750 |

> 年末习惯法下，运营期首年（第1年）净现金流 = 800 - 350 = 450 万元；
> 第8年额外加上期末残值回收 300 万元：800 - 350 + 300 = 750 万元。

### 2. 基本方案 IRR

设 IRR = i，令 NPV = 0：

$$-2500 + 450 \times \frac{(1+i)^8 - 1}{i(1+i)^8} + 300 \times \frac{1}{(1+i)^8} = 0$$

利用线性内插法近似求解：

- 试 i = 9%：$PV_{运营} = 450 \times 5.5348 = 2490.7$；$PV_{残值} = 300 \times 0.5024 = 150.7$；NPV = 2490.7 + 150.7 - 2500 = **141.4 万元 > 0**
- 试 i = 10%：$PV_{运营} = 450 \times 5.3349 = 2400.7$；$PV_{残值} = 300 \times 0.4665 = 139.9$；NPV = 2400.7 + 139.9 - 2500 = **40.6 万元 > 0**
- 试 i = 11%：$PV_{运营} = 450 \times 5.1461 = 2315.7$；$PV_{残值} = 300 \times 0.4339 = 130.2$；NPV = 2315.7 + 130.2 - 2500 = **-54.1 万元 < 0**

线性内插：

$$IRR \approx 10\% + \frac{40.6}{40.6 + 54.1} \times 1\% \approx 10.43\%$$

**基本方案 IRR ≈ 10.43% > ic = 6%，项目可行。**

### 3. 敏感性分析（变化幅度 ±10%）

每次只变动一个因素，其他不变，求对应的 IRR。

#### （1）建设投资 I 变动 ±10%

| 情况 | I（万元） | 净现金流变化 | 试算 IRR |
|:---|:---:|:---|:---:|
| -10% | 2250 | 第0年 -2250 | **≈ 12.2%** |
| 基本 | 2500 | 第0年 -2500 | **≈ 10.4%** |
| +10% | 2750 | 第0年 -2750 | **≈ 8.8%** |

验证（+10%，i=9%）：$450 \times 5.5348 + 300 \times 0.5024 - 2750 = 2641.4 - 2750 = -108.6$（NPV<0，需调低i）
调整至 i=8.5%：$450 \times 5.5892 + 300 \times 0.5264 = 2515.1 + 157.9 - 2750 = -76.9$
调整至 i=8%：$450 \times 5.7466 + 300 \times 0.5403 = 2586.0 + 162.1 - 2750 = -1.9$
调整至 i=7.9%：$450 \times 5.7686 + 300 \times 0.5452 = 2595.9 + 163.6 - 2750 = +9.5$

$I+10\%$ 对应 IRR ≈ 7.95% → 约 **8.0%**

验证（-10%，i=12%）：$450 \times 4.9676 + 300 \times 0.4039 = 2235.4 + 121.2 - 2250 = +106.6$
调整至 i=13%：$450 \times 4.7988 + 300 \times 0.3714 = 2159.5 + 111.4 - 2250 = +20.9$
调整至 i=13.5%：$450 \times 4.7097 + 300 \times 0.3534 = 2119.4 + 106.0 - 2250 = -24.6$

$I-10\%$ 对应 IRR ≈ 13.3% → 约 **13.3%**

#### （2）营业收入 R 变动 ±10%

| 情况 | R（万元） | 运营期净现金流（第1-7年） | 第8年净现金流 | 试算 IRR |
|:---|:---:|:---:|:---:|:---:|
| -10% | 720 | 720-350=**370** | 370+300=**670** | **≈ 7.5%** |
| 基本 | 800 | 800-350=**450** | 450+300=**750** | **≈ 10.4%** |
| +10% | 880 | 880-350=**530** | 530+300=**780** | **≈ 13.4%** |

验证（R-10%，i=7%）：$370 \times 5.7466 + 300 \times 0.5820 - 2500 = 2126.2 + 174.6 - 2500 = -199.2$
调整至 i=6%：$370 \times 5.9713 + 300 \times 0.6274 = 2209.4 + 188.2 - 2500 = -102.4$
调整至 i=5%：$370 \times 6.2064 + 300 \times 0.6768 = 2296.4 + 203.0 - 2500 = -0.6$

$R-10\%$ 对应 IRR ≈ 5.0%

验证（R+10%，i=13%）：$530 \times 4.7988 + 300 \times 0.3714 = 2543.4 + 111.4 - 2500 = +154.8$
调整至 i=15%：$530 \times 4.4873 + 300 \times 0.3269 = 2378.3 + 98.1 - 2500 = -23.6$
调整至 i=14%：$530 \times 4.6389 + 300 \times 0.3506 = 2458.6 + 105.2 - 2500 = +63.8$
调整至 i=14.5%：$530 \times 4.5648 + 300 \times 0.3392 = 2419.3 + 101.8 - 2500 = +21.1$

$R+10\%$ 对应 IRR ≈ 14.8%

#### （3）经营成本 C 变动 ±10%

| 情况 | C（万元） | 运营期净现金流（第1-7年） | 第8年净现金流 | 试算 IRR |
|:---|:---:|:---:|:---:|:---:|
| -10% | 315 | 800-315=**485** | 485+300=**785** | **≈ 13.0%** |
| 基本 | 350 | 800-350=**450** | 450+300=**750** | **≈ 10.4%** |
| +10% | 385 | 800-385=**415** | 415+300=**715** | **≈ 7.8%** |

### 4. 敏感性分析汇总表

| 变动因素 | -10% | 基本方案 | +10% | 敏感程度 |
|:---|:---:|:---:|:---:|:---:|
| 建设投资 I | ~13.3% | 10.4% | ~8.0% | ★★☆ 最弱 |
| 营业收入 R | ~5.0% | 10.4% | ~14.8% | ★★★ 最强 |
| 经营成本 C | ~13.0% | 10.4% | ~7.8% | ★★☆ 中等 |

> 注：两种系数表（7年年金+终值 vs 8年年金）会导致具体 IRR 数值略有差异，但排序结果 R > C > I 稳定一致。

### 5. 结论

**敏感性排序：R > C > I（营业收入 > 经营成本 > 建设投资）**

> 套用考试标准答题模板：
>
> "通过敏感性分析可知，营业收入对项目内部收益率影响最大，其次为经营成本，建设投资影响最小。因此，项目风险主要来源于市场收入的不确定性，需重点关注收入波动对项目经济效益的冲击。"

**补充提示：** 若题目要求"按敏感度排序"，则按 |ΔIRR| 从大到小排列：
> **营业收入 R（|ΔIRR| ≈ ±4.5%）> 经营成本 C（|ΔIRR| ≈ ±2.6%）> 建设投资 I（|ΔIRR| ≈ ±2.3%）**

## Problem 2：增值税及即征即退计算

### 1. 收入分类与销项税额

题目仅给出税率 13%，作业题语境下所有收入统一按 13% 计税。

| 收入类型 | 金额（万元） | 销项税额（万元） | 备注 |
|:---|:---:|:---:|:---|
| 开发软件收入 | 9500 | 9500 × 13% = 1235 | |
| 嵌入式软件（软件部分） | 900 - 700 = **200** | 200 × 13% = 26 | 硬件 700 万单独为硬件收入 |
| 本地化改造收入 | 100 | 100 × 13% = 13 | |
| 维护费 | 80 | 80 × 13% = 10.4 | 作业题统一 13% |
| **软件产品收入合计** | **9880** | 1284.4 | |
| 硬件收入 | 700 | 700 × 13% = 91 | |

**销项税额合计** = 1235 + 26 + 13 + 10.4 + 91 = **1375.4 万元**

### 2. 应纳税额

$$应纳税额 = 1375.4 - 320 = 1055.4 \text{ 万元}$$

### 3. 即征即退判断

软件产品收入 = 9880 万元，软件产品销项税额 = 1284.4 万元。

作业题简化处理：全部进项税额 320 万元由软件产品承担（题目未说明硬件有独立进项）。

$$软件应纳税额 = 1284.4 - 320 = 964.4 \text{ 万元}$$

$$税负率 = \frac{964.4}{9880} \approx 9.76\% > 3\%$$

**满足即征即退条件。**

### 4. 即征即退金额

$$即征即退 = 964.4 - 9880 \times 3\% = 964.4 - 296.4 = 668 \text{ 万元}$$

### 5. 结果汇总

| 项目 | 金额（万元） |
|:---|---:|
| 当月销项税额 | 1375.4 |
| 当月进项税额 | 320.0 |
| **当月应纳增值税** | **1055.4** |
| 软件产品税负率 | ≈ 9.76%（>3%，可申请即征即退） |
| **即征即退增值税额** | **668.0** |
