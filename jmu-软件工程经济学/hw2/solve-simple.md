## Problem 1：IRR 敏感性分析

**净现金流：第0年 -2500；第1~7年 450；第8年 750（含残值300）**

### 基本方案 IRR

- 试 i=10%：NPV = -2500 + 450×(P/A,10%,7) + 300×(P/F,10%,8) = -2500 + 450×4.868 + 300×0.467 = +40.9
- 试 i=12%：NPV = -2500 + 450×4.564 + 300×0.404 = -143.2
- 内插：IRR = 10% + 40.9/(40.9+143.2)×2% ≈ **10.4%** > 6%，项目可行

### 敏感性分析汇总（±10%）

| 因素 | -10% | 基准 | +10% | |ΔIRR| |
|:---|:---:|:---:|:---:|:---:|
| 建设投资 I | ~12.5% | 10.4% | ~8.5% | 2.0% |
| 营业收入 R | ~6.9% | 10.4% | ~13.8% | 3.5% |
| 经营成本 C | ~12.7% | 10.4% | ~8.2% | 2.2% |

### 结论

**敏感性排序：R > C > I（营业收入最敏感）**

> "通过敏感性分析可知，营业收入对项目内部收益率影响最大，其次为经营成本，建设投资影响最小。项目风险主要来源于市场收入的不确定性。"

## Problem 2：增值税及即征即退

**收入分类（统一按 13%，嵌入式软件拆出硬件 700 万）：**
- 开发软件 9500 + 嵌入式软件（软件部分）200 + 本地化改造 100 + 维护费 80 = **软件收入 9880 万**
- 硬件收入 700 万

**销项税额：** (9500+200+100+80+700) × 13% = 10580 × 13% = **1375.4 万元**

**应纳税额：** 1375.4 - 320 = **1055.4 万元**

**即征即退（软件 9880 万）：**
- 软件销项 = 9880 × 13% = 1284.4 万，进项全归软件 = 320 万
- 软件应纳税 = 1284.4 - 320 = 964.4 万
- 税负率 = 964.4/9880 ≈ **9.76% > 3%**，可即征即退
- **即征即退 = 964.4 - 9880×3% = 668.0 万元**
