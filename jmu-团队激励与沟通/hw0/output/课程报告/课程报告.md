## 1. 任务背景

### 1.1 任务描述

本次课程报告的实践任务基于课堂派发布的"新闻大调查"作业要求：针对校园或社会热点问题制定采访稿，拍摄视频并完成调查计划与总结分析报告。我选择的主题是**"生成式AI是技术革命还是泡沫？"**——这是一个自2023年以来持续发酵的社会热点话题。ChatGPT、GitHub Copilot、Midjourney等生成式AI工具的爆发式普及，引发了"技术革命论"与"泡沫论"的激烈争论。作为计算机专业的学生，我认为这个话题既有专业相关性，又有社会讨论价值。

**任务目标**：
- 完成3位不同身份受访者的实地采访
- 剪辑一段不超过3分钟的采访视频
- 撰写调查计划（事前）与总结分析报告（事后）
- 产出高质量的字幕文件

**时间范围**：1周（选题→采访→剪辑→分析→报告撰写）

**预期成果**：调查计划1份、采访视频1份（≤3分钟）、字幕文件3份、分析报告1份

### 1.2 任务当前面临的挑战

虽然作业要求4-6人一组，但由于个人选课安排的特殊性，我决定**独立完成全部任务**。这带来了以下挑战：

- **单人压力大**：策划、采访、拍摄、剪辑、分析全流程一人承担，任务量大
- **缺少团队讨论环节**：无法通过头脑风暴完善采访问题的深度
- **受访者协调难度**：需要同时协调两位老师（李旺老师、叶文来老师）和一位同学的时间
- **设备与工具依赖**：需要自备录音录像设备，并学习使用AI转录工具

## 2. 团队组建

### 2.1 成员构成

虽然形式上是我一个人独立完成整个项目，但从任务协作的角度来看，受访者实际上承担了"项目协作者"的角色。整个项目可以看作一个**虚拟团队**，成员构成如下：

| 成员 | 在本项目中的角色 | 分工职责 |
|---|---|---|
| **我（项目负责人）** | 统筹策划、采访执行、后期处理、报告撰写 | 全流程负责 |
| **李旺老师** | 受访专家 / 内容审议员 | 提供技术层面的深度分析 |
| **叶文来老师** | 受访专家 / 项目指导 | 提供前瞻性观点与方向指引 |
| **同学** | 学生代表受访者 | 提供学生群体的真实视角 |

### 2.2 贝尔宾团队角色分析

根据贝尔宾团队角色理论，一个高效团队需要9种角色的互补搭配。在本项目的虚拟团队中，角色分配如下：

| 成员 | 贝尔宾角色 | 行为特征与贡献 |
|---|---|---|
| **我** | 协调者 + 完成者 | 统筹项目全局，推动各环节执行，确保最终成果质量 |
| **李旺老师** | 审议员 | 审慎判断，提供技术层面的理性分析（"AI泡沫居多"） |

这种角色分配体现了**一人多角色 + 外部协作者**的灵活团队模式。虽然缺少了"推进者""外交家"等角色的覆盖，但通过我作为协调者的主动补位，项目依然顺利推进。

## 3. 问题诊断与需求分析

### 3.1 激励问题分析

#### 3.1.1 自身激励问题

独立完成团队任务面临的首要问题是**动力维持**。缺少队友的监督和鼓励，人容易陷入拖延和懈怠。结合**马斯洛需求层次理论**分析：

| 需求层次 | 对应的激励因素 | 在本项目中的体现 |
|---|---|---|
| 生理需求 | 基本无影响 | — |
| 安全需求 | 稳定的作业评价体系 | 明确评分标准降低不确定性 |
| 归属与爱 | **缺失** | 缺少团队归属感是最大挑战 |
| 尊重需求 | 受访者的认可、自我尊重 | 完成高质量采访获得老师和同学的尊重 |
| 自我实现 | **成就感驱动** | 独立完成全流程带来的成就感是核心动力 |

> 分析可见，**归属感缺失**是单人模式下的天然短板，需要通过强化**自我实现需求**来弥补。

#### 3.1.2 受访者的激励问题

受访者（尤其是两位老师）课务繁忙，为什么愿意配合采访？从激励角度分析：

- **李旺老师**：被采访体现其专业权威性（尊重需求），且话题与自身专业相关（自我实现）
- **叶文来老师**：作为课程指导教师，有指导学生完成作业的责任感，同时也对AI话题有自己的见解
- **同学**：轻松的非正式采访环境，满足其表达欲和被倾听的需求

### 3.2 沟通问题分析

#### 3.2.1 识别沟通障碍

在项目实施过程中，识别出以下沟通障碍：

| 障碍类型 | 具体表现 |
|---|---|
| 信息传递不畅 | 采访问题设计不够精准，受访者可能理解偏差 |
| 时间协调困难 | 老师课间时间有限，采访可能被打断 |
| 经验不足 | 作为第一次进行新闻采访，提问技巧不够成熟 |
| 设备限制 | 手机录音可能受环境噪音干扰 |

#### 3.2.2 使用沟通漏斗模型分析

沟通漏斗模型指出：**心中所想 → 表达出来 → 对方听到 → 对方理解 → 对方记住**，每一层都会发生信息衰减。

以采访场景为例：

```
我心中想了解：AI对教育方式的真实影响
    ↓
我表达的问题："相比没有AI的时代，今天AI时代我们的学习方式有什么区别？"
    ↓
受访者听到：AI时代的学习方式
    ↓
受访者理解：他想让我对比有AI和没AI的学习方法
    ↓
受访者记住并回答：重点回答了"工具变先进了"
```

本次采访中，信息衰减基本控制在可接受范围内，但仍有改进空间——特别是追问环节可以更深入。

## 4. 团队激励设计

### 4.1 理论依据

本项目的激励方案主要基于以下两种激励理论：

#### （1）赫茨伯格双因素理论

双因素理论将影响因素分为**保健因素**（不满意因素）和**激励因素**（满意因素）。在本项目中：

| 类型 | 因素 | 具体措施 |
|---|---|---|
| **保健因素** | 外部条件保障 | 提前预约受访者时间、提供舒适采访环境、准备备用录音设备 |
| **激励因素** | 成就与认可 | 自我成就感（独立完成复杂任务）、受访者的认可与反馈 |
| **激励因素** | 责任与成长 | 承担完整的项目管理责任、提升采访与剪辑技能 |
| **激励因素** | 工作本身 | 选题具有趣味性和讨论价值，采访过程本身激发求知欲 |

#### （2）目标设定理论

洛克的目标设定理论指出：**明确且具有挑战性的目标能够带来更高的绩效**。我为自己设定了如下SMART目标：

| 维度 | 目标内容 |
|---|---|
| Specific（具体） | 完成3位不同身份受访者的采访 |
| Measurable（可衡量） | 产出3份SRT字幕、1份视频（≤3min）、2份报告 |
| Achievable（可实现） | 1周内可完成，工具（手机+电脑+Buzz）已就位 |
| Relevant（相关） | 与课程要求直接相关 |
| Time-bound（有时限） | 1周截止 |

### 4.2 具体激励措施

#### 针对自己（自我激励）

- **阶段性奖励**：每完成一个采访，允许自己休息放松（符合目标设定理论的即时反馈原则）
- **进度可视化**：在计划表上打勾，形成视觉反馈
- **正向自我对话**：不断提醒自己"一个人也能完成"

#### 针对受访者（协作激励）

- **尊重时间**：严格按预约时间进行，不超时
- **成果分享**：转录完成后将字幕和视频分享给受访者，形成反馈闭环
- **致谢表达**：采访结束后当面感谢，并发送正式致谢信息

### 4.3 PREP模型应用示例

以"为什么需要提前发送采访提纲给受访者"为例：

| 步骤 | 内容 |
|---|---|
| **P**oint | 提前发送采访提纲能显著提升采访质量 |
| **R**eason | 根据沟通理论，提前告知话题能让受访者有时间准备，回答更具深度 |
| **E**xample | 李旺老师在收到提纲后，提前思考了AI技术本质的问题，给出了"泡沫居多"的深入分析 |
| **P**oint | 因此，采访前发送提纲是保证沟通质量的关键措施 |

## 5. 沟通计划

### 5.1 理论依据

本项目的沟通策略主要依据以下沟通模型和原则：

- **PREP模型**（Point-Reason-Example-Point）：用于设计采访问题和沟通要点
- **非暴力沟通原则**（观察-感受-需要-请求）：用于采访时的提问方式，避免引导性问题

### 5.2 具体沟通措施

#### 5.2.1 沟通机制

| 沟通环节 | 形式 | 时长 | 参与方 |
|---|---|---|---|
| 预约沟通 | 当面/微信 | 5分钟 | 你 + 受访者 |
| 正式采访 | 面对面录像 | 3-5分钟 | 你 + 受访者 |
| 内容确认 | 微信发送转录文本 | — | 你 → 受访者 |
| 感谢反馈 | 微信/当面 | 2分钟 | 你 → 受访者 |

#### 5.2.2 采访提纲设计（PREP结构）

**核心问题一：AI是技术革命还是泡沫？**

| 步骤 | 内容 |
|---|---|
| **P**oint | "现在关于生成式AI有不同的声音，有的人说它是技术革命，有的人说它是泡沫" |
| **R**eason | "因为想听听您的专业/真实看法" |
| **E**xample | "比如有的人觉得AI编程已经大幅提升了效率，但也有人认为它本质还是统计模型" |
| **P**oint | "您自己怎么看？" |

**核心问题二：AI对学习方式的影响**

| 步骤 | 内容 |
|---|---|
| **P**oint | "相比没有AI的时代，今天AI火热的背景下" |
| **R**eason | "作为计算机专业的学生，特别想知道学习方式应该如何调整" |
| **E**xample | "比如以前遇到问题需要翻书，现在可以直接问AI" |
| **P**oint | "您觉得主要区别在哪里？" |

#### 5.2.3 工具使用

- **录音/录像**：手机 + 备用录音
- **转录工具**：Buzz（使用Whisper Medium模型，NVIDIA CUDA 12.9 GPU加速）
- **剪辑工具**：视频剪辑软件
- **沟通工具**：微信（预约+确认）

## 7. 实践案例与反思

### 7.1 案例描述

**案例一：采访李旺老师——意外的"泡沫论"**

在采访李旺老师时，我原以为作为计算机专业教师，他会对AI持积极态度。出乎意料的是，他认为"泡沫居多"，并给出了技术层面的理由——"AI依然还是基于统计的东西，和以前的作法差不多，只是量级大一点点"。这个观点与我的预设完全不同，但却为报告增添了宝贵的辩证视角。

**案例二：Buzz AI转录工具的使用**

采访完成后，我使用Buzz工具配合NVIDIA RTX 3060 GPU进行自动语音识别转录。Whisper Medium模型在GPU上运行，3个总长约6分钟的视频在约1分钟内完成了转录，生成了准确率较高的SRT字幕文件。这本身就是一个"AI提升效率"的鲜活案例——恰好呼应了采访主题。

### 7.2 效果分析

**沟通方面**：
- 提前发送采访提纲有效提升了回答质量
- 采访中，两位老师都给出了有深度的分析，同学的回答则更贴近实际使用体验
- 三次采访均未出现明显的沟通障碍，说明计划中的沟通策略有效

**激励方面**：
- 自我设立的阶段性奖励（完成一个采访后休息）确实维持了动力
- 受访者在采访过程中表现出配合意愿，说明尊重他们的时间就是最好的激励

### 7.3 反思与改进

**不足之处**：
1. **缺乏追问深度**：单人采访时，有时未能及时对受访者的回答进行深入追问，错过了进一步挖掘观点的机会——如果有队友协助记录和补充提问会更好
2. **激励措施单一**：对受访者的激励主要是精神层面的尊重和感谢，缺乏物质激励的设计（如准备小礼品）
3. **时间管理可优化**：虽然按计划完成，但个别环节（如视频剪辑）占用了比预期更多的时间

**改进方向**：
1. 如果条件允许，可以邀请一位同学担任"采访助理"角色，帮助记录和补充提问
2. 为受访者准备小礼品（如一杯奶茶）能更好地体现感谢
3. 引入AI辅助剪辑工具进一步缩短后期时间——正如采访中讨论的，善用AI能提升效率

### 8.2 团队激励与沟通理论的实践感悟

**关于激励**：
独自完成小组级任务最大的挑战不是能力，而是持续的动力。通过**目标设定理论**中的SMART原则拆解任务、**双因素理论**中的激励因素（成就感、责任感）驱动自己，以及将受访者纳入"虚拟团队"的协作体系，我证明了合理运用激励理论可以在个体层面也产生持续的行动力。

**关于沟通**：
本次实践让我认识到，**沟通的质量取决于准备的质量**。提前设计结构化的采访提纲（运用PREP模型）、尊重受访者的时间与表达方式（非暴力沟通原则）、以及通过技术工具（Buzz转录）建立反馈闭环，都是有效沟通的关键环节。

**关于"一人团队"**：
独立完成小组任务并不意味着完全脱离协作。将外部相关者有效纳入自己的项目流程中，运用激励与沟通理论管理好每一段协作关系，同样可以达到甚至超越传统团队的效果。这本身就是一种**跨角色协调能力**的体现。
