# 作业五：范围管理——校园点评 App（CampusReview）

## 0. 项目确定

**项目名称：** CampusReview 校园点评 App

**项目背景：** 校园内信息不对称问题突出：选课时缺乏真实课程评价参考，食堂窗口好坏全靠口耳相传，设施报修进度不透明。学生需要一个集中化的平台，可以匿名发表真实评价、查看他人反馈，帮助做出更好的校园生活决策。

**项目类型：** 微信小程序 + 后端管理系统

---

## 1. 关键干系人及主要需求

| 干系人 | 角色 | 主要需求 |
|:------|:----|:---------|
| 在校学生 | 核心用户 | 匿名点评课程/食堂/设施；搜索查看他人评价；按维度打分（教学质量/口味/卫生）；举报不实内容 |
| 教务处 | 监管方 | 查看课程评价汇总数据；处理虚假/恶意评价投诉；导出评价报表用于教学评估参考 |
| 食堂商户/窗口 | 被评方 | 查看本窗口评价与评分；回复评价解释；获取改进建议数据 |
| 校方管理（后勤/信息中心） | 运营方 | 审核敏感内容；管理用户封禁；查看设施报修统计 |
| 开发团队 | 实施方 | 清晰的需求文档；合理的迭代计划；可维护的代码架构；完善的测试用例 |

## 4. 范围说明书

### 项目目标

开发一款校园匿名点评小程序，支持学生对课程、食堂、设施进行评分与文字评价，并提供搜索、筛选、举报、报修等功能，10 周内完成 v1.0 上线。

### 包含的工作（In Scope）

| 模块 | 具体内容 |
|:----|:---------|
| 课程点评 | 按课程名称/教师搜索；五星评分制 + 文字评价；匿名发表；查看历史评价汇总 |
| 食堂点评 | 按食堂/窗口浏览；口味/卫生/服务多维度打分；上传图片评价；商家回复 |
| 设施报修 | 提交报修（位置+描述+照片）；查看处理进度；报修历史记录 |
| 用户系统 | 微信授权登录；匿名昵称生成；个人评价/报修管理 |
| 内容审核 | 敏感词过滤；用户举报；管理员后台审核/下架 |
| 搜索与筛选 | 关键词搜索；按评分/时间排序；按分类筛选 |

### 不包含的工作（Out of Scope）

| 项目 | 说明 |
|:----|:------|
| 外卖配送功能 | 本平台不做在线点餐与配送 |
| 二手交易市场 | 不与点评功能耦合 |
| 即时通讯/私信 | 用户间不支持直接聊天 |
| 支付功能 | 不涉及任何线上支付交易 |
| 校园论坛/社交 | 不做帖子、动态等泛社交功能 |
| 多端适配（iOS/Android 原生） | v1.0 仅支持微信小程序，后续迭代考虑 |

### 约束与假设

- **约束：** 必须在 10 周内交付 v1.0；开发团队 4-5 人；仅支持微信小程序端
- **假设：** 校方提供课程基础数据接口；用户通过微信授权即可登录；内容审核初期使用自动化敏感词过滤 + 人工抽检
